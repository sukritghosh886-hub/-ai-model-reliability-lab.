About this lab

    
This prototype has two independent functions: rule-based code diagnostics and binary classification evaluation.

    
Code diagnostics

    
Uses simple rules to flag selected common problems. It does not execute uploaded code, run a compiler, call an AI model, or guarantee that a correction is valid.

    
Model reliability

    
Calculates metrics from labeled predictions supplied by the user. Results depend on the quality and representativeness of that dataset.

    
Privacy and safety

    
Processing happens in the page's JavaScript. Files are not intentionally uploaded to a server by this code. Do not paste passwords, API keys, or confidential source code into a shared device.

    
Current limitations

    
    
      
  • No automatic execution or sandbox for arbitrary code.
    • 
      
  • No AI-generated fixes or semantic understanding yet.
    • 
      
  • No multi-class metrics or model-training workflow.
    • 
      
  • Static code rules can miss errors and can flag valid code.
